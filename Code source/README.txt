Explications pour lancer le projet : 
-créer la base de données "eventhallmanager" dans pgadmin.
-veiller à ce que le "spring.datasource.password", dans le fichier application.properties corresponde au mot de passe mis dans pgadmin.
-le port du server a été défini sur 8081 dans le fichier applications.properties, donc après avoir lancé l'application, taper cet url:"http://localhost:8081/login", 
dans le navigateur.
-l'url vous envoie sur la page de connexion.
-pour vous connecter en tant que "ADMIN", entrez les identifiants suivants prédéfinis dans le code source :
	email : admin@gmail.com	
	mot de passe : admin123
-pour vous connecter en tant que "USER", d'abord créer un compte sur la page d'inscription, qui ne permet que de créer des comptes "USER", et créez le compte, 
puis connectez-vous.
